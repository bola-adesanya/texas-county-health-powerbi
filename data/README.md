# Data folder

Place source CSV files in a local folder named:

```text
data/raw/
```

This folder is intentionally ignored by Git.

Expected grain:

```text
One row per Texas county per year
```

Expected fields include county identifiers, population, demographic percentages, disease counts and rates, mortality rates, poverty, insurance, employment, and birth outcome indicators.

Do not commit raw data unless you have confirmed the dataset license permits redistribution.
