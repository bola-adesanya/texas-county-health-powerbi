# Project overview

## Objective

Build a Power BI dashboard that analyzes Texas county-level public health data across population, demographics, mortality, injury, infectious disease, insurance, poverty, birth outcomes, and employment indicators.

## Analytical scope

The project converts function-style data access tasks into report-ready analytics:

- County population lookup
- Highest demographic percentages by county
- Highest and lowest mortality or injury rates
- Food stamp utilization relative to poverty
- Largest single-year pertussis jump
- Low birth weight micro-average by uninsured-rate band
- Employment extract for XML-ready analysis
- Infectious disease extract for JSON-ready analysis

## Audience

This portfolio project is designed for:

- Healthcare analytics hiring managers
- Public health data teams
- Biomedical informatics programs
- Product and analytics leaders evaluating data storytelling ability

## Skills demonstrated

- Data import from multiple CSV files
- Power Query cleaning and transformation
- Star schema design
- DAX ranking and weighted measures
- Healthcare/public health metric interpretation
- Dashboard storytelling
- GitHub documentation
